# 电源计划管理器隐私政策

生效日期：2026 年 8 月 2 日

电源计划管理器不会收集、传输、出售或共享个人信息。

应用仅为在用户设备上显示和管理电源计划而读取 Windows 电源计划的名称与标识符。快捷槽位绑定、每日时间段、语言、应用偏好和本地启动诊断日志仅保存在应用的本地数据目录中。诊断日志包含应用启动检查点和错误详情，绝不会被传输。应用不包含分析、广告、账号、云同步或网络通信功能。

通过 Windows 卸载本应用时，其应用包本地数据会按照 Windows 应用数据机制被移除。用户也可以在 Windows 设置中重置应用。

如对本政策有疑问，请联系 Microsoft Store 应用页面中公布的支持地址。
