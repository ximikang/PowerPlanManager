# Power Plan Manager Privacy Policy

Effective date: 2026-08-02

Power Plan Manager does not collect, transmit, sell, or share personal information.

The application reads the names and identifiers of Windows power plans solely to display and manage them on the user's device. Slot mappings, daily schedule ranges, language, application preferences, and a local startup diagnostic log are stored only in the application's local data directory. The diagnostic log contains application checkpoints and error details and is never transmitted. The application has no analytics, advertising, account, cloud synchronization, or network communication feature.

Uninstalling the application through Windows removes its packaged local data according to Windows application-data behavior. Users can also reset the application from Windows Settings.

Questions about this policy may be sent to the support address published on the application's Microsoft Store listing.
