# Microsoft Store 应用页面 — 简体中文

## 名称

电源计划管理器

## 简短说明

从系统托盘快速切换 Windows 电源计划，并按每日时间段自动管理。

## 说明

电源计划管理器让常用的 Windows 电源计划触手可及。你可以把四个快捷模式绑定到标准、OEM 或自定义计划，从任务栏通知区域切换，并用每天重复的时间段自动管理当前计划。

主要功能：

- 节能、平衡、高性能和卓越性能四个快捷槽位
- 可绑定设备上的任意 OEM 或自定义电源计划
- 支持多个每日时间段和跨午夜时间段
- 手动切换保持到下一个定时节点
- 登录、睡眠恢复和系统时间变化后自动重新计算
- 简体中文和英文界面
- 无账号、无分析、无广告、无网络访问，所有设置仅保存在本机

电源计划的可用性和实际效果取决于设备、OEM 配置、Modern Standby 支持和组织策略。本应用不会绕过 Windows 策略，也不会请求管理员权限。

## 关键词

电源计划，节能，高性能，定时，托盘，电池
