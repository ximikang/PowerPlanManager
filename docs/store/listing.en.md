# Microsoft Store listing — English

## Name

Power Plan Manager

## Short description

Switch and schedule Windows power plans directly from the system tray.

## Description

Power Plan Manager puts your Windows power plans within easy reach. Bind four quick modes to standard, OEM, or custom plans, switch from the notification area, and automate the active plan with repeating daily time ranges.

Features:

- Power saver, Balanced, High performance, and Ultimate performance quick slots
- Custom mapping to any power plan available on the device
- Multiple daily time ranges, including overnight ranges
- Manual override until the next scheduled boundary
- Automatic recovery after sign-in, sleep, and system time changes
- English and Simplified Chinese interface
- Local-only settings with no account, analytics, advertising, or network access

Power plan availability and behavior depend on the device, OEM configuration, Modern Standby support, and organization policy. The app never bypasses Windows policy or requests administrator elevation.
